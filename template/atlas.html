Data health

The update pipeline runs on a schedule with no AI involved. It retries, switches to backup endpoints, keeps last-good data, and swaps dead links for archived copies. When something stays broken, it opens a GitHub issue that emails the owner. It closes the issue again once the problem clears.

Method: triangulate. Compare each side's readout of the same meeting, compare what trading partners report about each other, and check claims against physical traces. "Bridges" covers documented, sourced contributions only. Inclusion records a specific cross-border act. It is not an endorsement of a person's wider record; caveats are on each card. Birthplaces follow the source, and the card notes when a place is now in another country.
